# Asset inventory

No assets were captured. This project runs in **no-capture mode**: the environment's
egress proxy blocks `a2ui.org` and the hosted Composer app, and the user supplied no
material of their own.

Every visual in this film is therefore **designed and built in composition HTML** — the
Composer workbench (assistant / preview / JSON editor / debug tabs), the streaming JSON,
the rendered widget, and the renderer badges are all authored elements, not screenshots.
This is a deliberate advantage for the chosen angle: authored panels animate natively and
can be driven frame-accurately, which a still plate with overlays cannot do.

Usable "assets" available to frames, all authored in-composition:

- `workbench-shell` — the four-panel Composer chrome (title bar, panel headers, tab strip).
- `json-stream` — A2UI v1.0 JSON payload, real component names, streamed line by line.
- `rendered-widget` — the flight-status widget the JSON describes, assembled component by component.
- `renderer-badges` — Angular / Lit / React, the three shipped Basic-catalog renderers.
- `a2ui-mark` — an authored geometric mark for the end lockup (two nodes + a streaming edge).
